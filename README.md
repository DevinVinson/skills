# Personal Skills

A public collection of the skills I use, keep up to date, and share.

Repository: <https://github.com/devinvinson/skills>

## What this repo contains

This repo stores skill source files in `skills/`.

Each skill lives in its own directory and usually includes a primary `SKILL.md`. Some skills may also include supporting files such as:

- `REFERENCE.md` for detailed notes
- `EXAMPLES.md` for practical examples

## Current skills

- [`standup`](./skills/standup/SKILL.md) — daily standup and task carryover workflow
- [`openhands-agent-server-ui`](./skills/openhands-agent-server-ui/SKILL.md) — reference skill for building browser UIs against a running OpenHands agent-server

## Structure

```text
skills/
  <skill-name>/
    SKILL.md
    REFERENCE.md   # optional
    EXAMPLES.md    # optional
```
